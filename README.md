# 📚 E-Cybrary

Welcome to **E-Cybrary**, a curated open-source digital library dedicated to cybersecurity, networking, programming, systems administration, and technical cheat sheets. 

The goal of this repository is to provide students, researchers, and self-learners with direct, frictionless access to high-quality technical literature completely free of charge.

## ⚖️ Open Source & Fair Use Notice
All educational materials, books, and resources hosted in this repository have been collected strictly from **open-source, public domain, or explicitly free-to-distribute resources**. This archive is built and maintained solely for **non-commercial, educational, and research purposes**. 

If you hold the rights to any document hosted here and believe its inclusion violates copyright terms, please open an Issue, and the material will be promptly evaluated and removed.

## 🗂️ Library Index

### 🛑 1. Cybersecurity & Penetration Testing
Comprehensive guides covering ethical hacking, infrastructure defense, bug hunting, application security, and social engineering.
* **Core Certifications:** CEH Foundations & Official Study Guides, ISC² CISSP Official Study Guide.
* **Methodologies & Playbooks:** *The Hacker Playbook 3*, *Penetration Testing: A Hands-On Introduction*, *Tribe of Hackers Red Team*.
* **Platform & Hardware Specifics:** *The Mobile Application Hacker's Handbook*, *iOS Hacker's Handbook*, *The Mac Hacker's Handbook*, *The IoT Hacker's Handbook*.
* **Web & Application Security:** *The Web Application Hacker's Handbook*, *Hacking APIs*, *Real-World Bug Hunting*.

From fundamental protocols to deep network scanning mechanics.

## 🚀 How to Use This Library

### Option A: Browse Online
You can navigate the folders directly via the GitHub UI above to locate the specific sub-field you want to study and read or download individual PDFs directly from your browser.

### Option B: Download the Entire Library
To keep a complete offline backup copy of this database on your local machine, run the following command in your terminal:

```bash
git clone https://github.com
```
